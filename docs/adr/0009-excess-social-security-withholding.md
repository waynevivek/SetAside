# Account for excess Social Security withholding from W-2 wages

The optional W-2 section collects Box 4 totals and a separate two-or-more-employers indicator for the taxpayer and, for Married Filing Jointly, the spouse. Estimate any eligible excess Social Security withholding separately and symmetrically for each person using Box 4 minus the active-year maximum employee Social Security tax, and apply that credit only when that person's two-or-more-employers requirement is satisfied. If the taxpayer indicates two or more employers and enters Box 4 above the annual maximum while Box 3 does not exceed the wage base, show a non-blocking validation warning. Keep the inputs in the collapsed section and explain Box 4 in plain language.
