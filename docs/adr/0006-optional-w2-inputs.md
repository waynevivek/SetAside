# Keep detailed W-2 inputs optional and collapsed

The calculator's main path stays focused on freelance revenue, expenses, filing status, and state. An optional section, collapsed by default, collects annual totals across the taxpayer's W-2s for Boxes 1, 2, 3, 4, 5, and 6, plus a separate indicator for whether the taxpayer had two or more employers. For Married Filing Jointly, it also collects the spouse's Box 1, 2, 4, 5, and 6 totals and a separate two-or-more-employers indicator, while excluding spouse Box 3 because spouse Social Security wages do not reduce the taxpayer's self-employment Social Security wage base. Explain each box in plain language and accept blank or zero values. This provides the wage, withholding, and payroll-credit distinctions needed by the estimate without turning the main calculator into a tax-preparation form.
