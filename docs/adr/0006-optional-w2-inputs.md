# Keep detailed W-2 inputs optional and collapsed

The calculator's main path stays focused on freelance revenue, expenses, filing status, and state. An optional section, collapsed by default, collects annual totals across the taxpayer's W-2s for Boxes 1, 2, 3, and 5. For Married Filing Jointly, it also collects the spouse's Box 1, 2, and 5 totals. Explain each box in plain language and accept blank or zero values. This provides the wage and withholding distinctions needed by the estimate without turning the main calculator into a tax-preparation form.
