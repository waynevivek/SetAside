# Include QBI with conditional high-income inputs

V1 includes the QBI deduction for the supported sole-proprietor business. Show specified-service trade status and qualified-property questions only when the selected tax year's rules make them relevant. If required information is unknown or missing, omit QBI and clearly disclose that the estimate may be higher than the user's actual federal tax liability. Validate the implementation against the active year's official Forms 8995 and 8995-A before release.
